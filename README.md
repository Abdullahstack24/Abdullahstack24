### 🚀 Featured Project

| | |
|---|---|
| **Project** | 🖐️ [HyperFusionFormer — Multimodal ASL Sign Language Recognition](https://github.com/Abdullahstack24/sign_language_recognition) |
| **What it does** | Classifies American Sign Language hand gestures by fusing visual features (Swin Transformer) with hand-skeleton geometry (Graph Neural Network) through Cross-Attention |
| **Result** | ✅ **99% test accuracy**, 0.99 macro F1-score on validated classes |
| **Pipeline** | MediaPipe landmark extraction → GCN/GATv2 graph branch + Swin Transformer vision branch → Cross-Attention fusion → classification |
| **Stack** | `Python` `PyTorch` `PyTorch Geometric` `MediaPipe` `OpenCV` `Scikit-learn` |
| **Status** | 3-class (A/B/C) validated at 99% accuracy — scaling to full 26-letter alphabet |
